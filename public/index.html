    In-game hotkeys

    Work while the game has focus, as long as the tray icon is running (Start with Windows, or tray.vbs).

    Ctrl+Shift+MMark the spot where you stand on the map
    Ctrl+Shift+OShow / hide the overlay
    Ctrl+Shift+LRepeat the last alert (with voice)

    How to set it up (5 minutes)
    1. Open discord.com/developers/applications → New Application → give it a name.
    2. Bot → Reset Token → copy the token and paste it below.
    3. Save, then click the invite link that appears and add the bot to your own server.
    4. Type /online, /boss, /whois, /today, /timers, /route, /screen, /chat, /whispers or /price in any channel. Only you see the answers.

    Screen reader 
    
      
    Looks at the game window every few seconds, the way you do, and reads HP, MP and EXP from the screen plus the loot announcements in the chat. It uses the text recognition built into Windows and never touches the game itself. Run the game in a window or borderless window; it keeps reading while other windows cover the game, but not while it is minimised. Only the numbers, the announcements, and the chat log and pictures you switch on below are kept.
